# trading_app — trading policy defaults (normative)

Mandatory reference for `AGENTS.md` (moved verbatim from `CLAUDE.md`, 2026-11-15). These are binding
defaults, not background: read this file before changing or reviewing agents, trading, model code,
`config.py` or `.env` defaults, and keep it in sync with `backend/config.py`.

## Trading policy defaults (env-tunable; tightened 2026-05-16)
- `TRAIL_GIVEBACK_PCT=0.10` — trailing-stop fires when current unrealized PnL has fallen 10 % below peak (was 0.20 before 2026-05-16; loose default cost ~$30K of peak portfolio value in chop)
- `TRAIL_ARM_USD=100.0` — trailing arms only once peak unrealized PnL reaches $100 (was $25; raises arm noise floor)
- `TRAIL_COOLDOWN_HOURS=4.0` — after any trailing-stop SELL fires, new BUYs across the agent's portfolio are blocked for this many hours. SELLs are never blocked. `0` disables. State lives in `BaseAgent._last_trail_stop_ts` (in-memory, non-persistent across restart).
- `XGB_FEATURE_FILTER` — 8-channel production set (reverted from 16-ch on 2026-05-16; 16-ch had fold-2 IC ≈ 0 in current regime). Both `signal_xgb.json` (main) and `signal_xgb_b{0..9}.json` (ensemble) must train on the **same** filter — `scripts/train_xgb_ensemble.py` now reads the env so they stay aligned.
- `W3_BLEND_ENABLED=1`, `W3_BLEND_WEIGHT=0.4` (added 2026-05-23) — XGBReasoningAgent fuses XGB prediction with `SignalW3` (per-group + regime-conditional blend; `backend/data/w3_model.py`). At predict-time: `pred = (1-W3_BLEND_WEIGHT)*xgb + W3_BLEND_WEIGHT*w3`. WFE gate uses `max(xgb.mean_wfe, w3.mean_wfe)` when blend enabled so a healthy W3 unblocks the agent even if XGB's WFE is negative. W3 is co-trained alongside XGB in `_train_blocking` (same 24-hour retrain cadence). See [[backlog_trading_app_w3_ensemble]] for derivation.
- `W3_DEVICE=cpu` (added 2026-05-23) — W3 **training** device. Default CPU keeps the GPU free for Ollama inference and eliminates CUDA state-leak cascades in the test suite (see [[backlog_trading_app_test_pollution]]). Sidecar/probe scripts set `W3_DEVICE=cuda` for faster iteration. **Inference is always CPU**, regardless of this setting — `predict()` never moves tensors to GPU.
- `VOL_TARGET_SIZING_ENABLED=0`, `VOL_TARGET_ANN_VOL=0.12`, `VOL_TARGET_CAP=2.0` (H15, added 2026-07-05) — **XGBReasoningAgent-only** vol-managed position sizing (Moreira-Muir). In `xgb_decision.decide_buy`, the Kelly base size is scaled by `w = clip(VOL_TARGET_ANN_VOL / rv_20d, 0, VOL_TARGET_CAP)` (rv_20d = symbol's *annualized* trailing realized vol via `signal_history.get_latest_rv_20d`) **before** the existing `[2%, MAX_POSITION_SIZE]` clamp — so per-position bounds are untouched; it only reallocates within that band (smaller for high-vol names, capped-larger for calm ones). **DEFAULT OFF (shadow-only):** while disabled, `w` is still computed and surfaced in the decision reason (`[volx0.25 shadow]`) and logged as `[VOL_TARGET]` at INFO, but sizing is unchanged — set `=1` to activate. Motivation: ledger Iteration 13 probe (vol-managed cut the real traded basket's drawdown ~54% rel while raising Sharpe). Pure function (invariant #10) — `w` computed from the config passed in; `realized_vol` threaded in via `BuyContext`. Applies to the XGB path only; other agents' sizing is unchanged.
- `TERM_STRUCTURE_GATE_ENABLED=0`, `TERM_STRUCTURE_PROXY=QQQ`, `TERM_STRUCTURE_Z_CUTOFF=0.5`, `TERM_STRUCTURE_DELTA_TOPPING=0.10`, `TERM_STRUCTURE_DELTA_WEAK=0.15` (added 2026-08-02) — **XGBReasoningAgent-only** multi-horizon trend term-structure gate. `data/regime_term_structure.py` (pure module, invariant #10) classifies the proxy's 5/10/20/60/90d momentum as vol-normalized z-scores (`z = mom / (vol20 · √(h/252))`) into `trending_up` / `topping` / `ranging_weak`, emitting a `gate_delta` (0 / 0.10 / 0.15). In `xgb_decision.decide_buy` Gate 3 the delta is combined with the regime add-on via **`max()` (never sum, never lowers the threshold)** — tighten-only; the WFE falsifier is unaffected. `XGBReasoningAgent.analyze` updates the detector once per cycle from `market_context[PROXY]["bars"]` (fail-open when <91 bars), reads the cached delta per-symbol into `BuyContext`. **DEFAULT OFF (shadow):** while disabled the state + delta are computed and logged (`[TERM_STRUCT]` on transition) but not applied — set `=1` to activate (backend restart). Motivation: the SPY-20d regime detector has two blind spots (single-horizon + wrong index — SPY held up while the tech-heavy book tracked NASDAQ down Jun–Jul). Spec: `docs/superpowers/specs/2026-08-01-regime-term-structure-gate-design.md`.
- `XGB_LLM_DECISION_MODE=ollama` (added 2026-05-24, Stage 1 of LLM-as-news-only) — XGBReasoningAgent per-symbol decision mode. `ollama` (default): existing 5-step LLM reasoning chain drives BUY/SELL/HOLD. `rule_based`: skip LLM entirely; decision = XGB+W3 blended direction (`bull→BUY`, `bear→SELL`, `neutral→HOLD`) with confidence = blended `cnn_conf`. **All existing gates apply identically** in both modes (WFE, max-positions, uPnL drawdown, lone-wolf, trail cool-down, Kelly sizing). Motivated by arxiv 2505.07078 showing LLM-driven trade decisions fail at trend detection over long horizons. Operator can A/B by flipping the env between cycles; no code change needed to switch modes.
- `HIST_PREARM_STOP_PCT=0.0`, `HIST_SEASONAL_WEIGHT=0.20`, `HIST_CONFIDENCE_CAP=0.0` (added 2026-08-02, ledger Iteration 15) — **HistoricalTrendsAgent-only** knobs, all three defaulting to **current behaviour** (opt-in). Scoped to this one agent deliberately: it is the book's best performer (+15.55%, rank 1/10), so it is the safest place to test chassis-level ideas before generalising — same containment pattern as H15's XGB-only rollout. All three live in `agents/historical_trends_agent.py`; **`base_agent.py` is NOT touched**, so no other agent's behaviour can change.
  - **`HIST_PREARM_STOP_PCT`** closes the *trail-arm gap*. `BaseAgent._check_trailing_stops` only arms once peak uPnL reaches `TRAIL_ARM_USD` ($100), so a position that never turns profitable has **no** protection between entry and `HARD_STOP_PCT` (−8%). Attribution over the agent's first 338 exits: that gap is the **entire** loss column (108 hard-stop exits, 0% win, −$56,474). When `> 0`, `_prearm_stop_signal()` emits a SELL once an *unarmed* position is down that fraction from entry, and returns `None` the moment the trail arms so the two stops never double up. Only covers symbols present in `market_context` that cycle; others still fall through to the hard stop. Suggested first trial `0.04`.
  - **`HIST_SEASONAL_WEIGHT`** tunes the seasonal pillar, whose sign is **inverted** on the live sample (May bias −0.14 was the best month at +$20.9K; July bias +0.07 the worst at −$14.8K). `_composite_weights()` renormalises channel/momentum/volume to absorb whatever seasonal gives up, so the composite always sums to 1.0 and the ±0.25 BUY/SELL thresholds keep their meaning. Set `0.0` to drop the pillar.
  - **`HIST_CONFIDENCE_CAP`** caps the confidence used for **sizing only**. Size scales with `confidence = |composite|`, but composite > +0.60 is the *only* net-negative entry bucket (22 trades, 45.5% win, −$691) while being sized largest. The confidence reported on the Signal stays uncapped and honest. Suggested first trial `0.45`.
