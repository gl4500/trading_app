Key observations

  • HistoricalTrendsAgent has the lowest base ensemble weight (0.08) but the best window performance (+3.97% / +$5,449). Base weights are nearly inverted from realized performance.
  • TechAgent has the highest base weight (0.23) but is near-flat (+0.91% / −$41).
  • Only XGBReasoningAgent consumes the 38-channel signal pool. Every other agent reads price/bars + optionally news directly — they bypass the model entirely.
  • The LLM cohort (Claude / Sentiment / Ollama) all share the same upstream pipeline: price + alpaca_news + yahoo_news + technicals_fmt. The differentiator is which LLM endpoint they hit.
  • Three agents are effectively inactive this window: GeminiAgent (0 trades, not in ensemble), OllamaAgent (0), EnsembleAgent (0 — failing 0.60 conviction threshold).
  • HistoricalTrendsAgent is the only consumer of the calendar source. Its hist_seasonal sub-score has +0.20 IC in the newest fold — strongest current-regime signal in the audit.
