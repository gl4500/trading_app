How to read this page

Each scenario below is a synthetic market state (catalyst + macro + momentum profile). For each, we show what the production XGB model would predict, what the W3 per-group blend model would predict, and what the ensemble agent actually emits after blending them at W3_BLEND_WEIGHT=0.40 (the live default).

The blend formula is final_pred = (1 - 0.4) × xgb_pred + 0.4 × w3_pred. WFE gate uses max(xgb.mean_wfe=-0.1023, w3.mean_wfe=not yet measured) — either model healthy → BUYs allowed.

Watch for the action FLIPS vs XGB tag — those are the scenarios where the W3 vote changes the agent's decision. The W3 per-group breakdown dropdown shows how each of the three groups (Catalyst / Momentum / Regime) contributed to the W3 prediction.
